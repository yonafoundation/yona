🚀 First-Time Google Drive Setup

Step 1 — Create Google Cloud Project

  1. Go to console.cloud.google.com → New Project → Name it YONA CMS
  2. Enable Google Drive API → APIs & Services → Enable APIs
  3. Create API Key → Credentials → Create API Key → Copy it below
  4. Restrict API key to Google Drive API only (recommended)

Step 2 — Create OAuth Client (for uploads)

  1. Go to Credentials → Create OAuth 2.0 Client ID → Web Application
  2. Under Authorised JavaScript origins, add your site URL (or http://localhost for local testing)
  3. Copy the Client ID and paste below

Step 3 — Initial Drive Setup

  1. Enter your API Key and Client ID below, then click "Connect Google Drive"
  2. Sign in with your Gmail account (supportyona@gmail.com)
  3. Click "Create Content File" — this creates yona-content.json in your Drive
  4. Your site will now read and write from that file!
